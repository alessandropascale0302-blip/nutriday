# NutriDay

Versione pronta per essere pubblicata su **GitHub Pages**.

## Pubblicazione su GitHub

1. Crea un nuovo repository su GitHub (per esempio `nutriday`).
2. Estrai questo ZIP.
3. Carica nel repository tutti i file presenti nella cartella.
4. Vai in **Settings → Pages**.
5. In **Build and deployment** scegli **Deploy from a branch**.
6. Seleziona il branch `main` e la cartella `/ (root)`.
7. Salva.

Dopo la pubblicazione, GitHub Pages fornirà l'URL del sito.

## Nota

`index.html` è già il punto di ingresso dell'app e non richiede Node.js, npm o una build aggiuntiva.
